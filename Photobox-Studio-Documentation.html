1. Deskripsi Aplikasi

Photobox Studio adalah aplikasi kiosk self-service untuk photo booth portabel. Aplikasi ini berjalan secara lokal di sebuah Windows Mini PC yang terpasang di dalam unit photobox fisik. Tidak membutuhkan hosting cloud — semua berjalan di localhost.

Pengguna (tamu di event/cafe/venue) berinteraksi langsung dengan layar sentuh di photobox. Mereka memilih paket, memilih frame, membayar via QRIS, berfoto, memilih filter, mendapatkan scan QR file digital, dan terakhir mengambil cetakan dari meja operator.

3. User Flow Terkini (Alur Pengguna)

🏠 Welcome → 📦 Select Package → 🖼️ Select Frame → 💳 Payment (QRIS) → 📷 Camera → 🎨 Filter Color → 👁️ Review → 🎉 QR Scan & Finish
💡 Alur Cetak (Print Flow) Sistem sekarang menerapkan bypass cetak box. Setelah men-scan QR Soft File, pelanggan akan diinstruksikan keluar box untuk mengambil cetakan kertas di meja operator / kasir.

4.5 — 📷 Camera (/camera)

File: src/pages/camera.astro

ItemDetail
CameraKamera DSLR Hardware via API (15 Detik Timeout). Fallback ke WebRTC Webcam.
MirrorSelfie mode (scaleX(-1)) pada Live Preview.
CaptureHTML5 Canvas capture → JPEG 90% quality
UI LayoutPanel Kanan bisa di-scroll (Tahan resolusi layar kecil) dengan Tombol Lanjut melayang statis di bawah bingkai.

Alur Sesi Foto

1. "Get Ready!" overlay (3 detik)
2. Hide overlay
3. Loop per foto (3x atau 4x):
   a. Countdown 3-2-1 (dengan sound beep)
   b. Flash putih + shutter sound
   c. API Capture trigger DSLR (Timeout 15s)
   d. Push Base64 hasil foto ke array localStorage
   e. "Captured!" badge animation
   f. Delay 2.5 detik antar foto
4. Tombol "Lanjut" muncul di bawah bingkai.
5. Tombol "Retake" per-foto tersedia jika ingin ulang spesifik gambar.
6. Lanjut → redirect ke /filter

5. Backend API Reference

Payment API

MethodEndpointRequestResponse
GET/api/generate-qris?package=basic{ transactionId, qrisUrl, amount, expiresIn }
POST/api/simulate-payment-success{ transactionId }{ success, message }
GET/api/payment-status/:txId—{ transactionId, status }

Hardware API

MethodEndpointResponse
POST/api/hardware/camera/triggerMengambil gambar dari DSLR hardware/trigger (bisa delayed sampai 15s)

Gallery API

MethodEndpointBodyResponse
POST/api/gallery{ photos[], strip, frameId, packageType }{ galleryId, downloadUrl, qrDataUrl }
GET/gallery/:id—HTML download page (mobile-friendly)
